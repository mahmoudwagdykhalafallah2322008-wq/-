# Mahmoud ❤ Basbousa — الموقع الرومانسي

## طريقة التشغيل
افتح ملف `index.html` في أي متصفح مباشرة، مفيش أي تثبيت أو build مطلوب.

## قبل ما تبعتيه/تستخدميه لازم تعمل حاجتين:

### 1. الأغنية 🎵
حط ملف الأغنية بتاعك في:
```
assets/music/amr-diab-love.mp3
```
لأسباب حقوق الملكية، محدش حط ملف أغنية أو كلمات الأغنية جوا المشروع — لازم تضيفه إنت بنفسك.
لو الملف مش موجود، زرار التشغيل هيفضل شغال بصريًا بس مش هيسمع صوت لحد ما تحط الملف.

### 2. الصور 📸
في `assets/images/` حطيت 6 صور بديلة (gradient بسيط) بأسماء:
```
memory1.jpg ... memory6.jpg
```
استبدلها بصوركم الحقيقية بنفس الأسماء (أو غيّري أسماء الملفات في `index.html` داخل قسم `gallery-section`).

## الملفات
```
index.html   → الهيكل
style.css    → التصميم (dark romantic + glassmorphism)
script.js    → كل التفاعل (عداد، مشغل الأغنية، الرسائل، الأنيميشن...)
assets/
  images/    → صور الذكريات
  music/     → الأغنية
```

## ملاحظة عن العداد
العداد بيحسب من:
```javascript
new Date("2026-07-20T13:00:00")
```
لحد اللحظة دي بالظبط، وبيتحدث كل ثانية لوحده.
